PROMPT

Crie um site premium, moderno e responsivo para a Studio Black7, uma barbearia de alto padrão localizada na Zona Norte de São Paulo. O site deve transmitir sofisticação, estilo urbano e confiança, com uma identidade visual em preto, dourado/cobre e branco, tipografia elegante (serifada ou display para títulos, sans-serif limpa para texto) e microanimações suaves (fade-in, hover states, scroll reveal).

Logo/monograma "RB" (Rayblack7) no header.
Estética: barbearia premium, minimalista, com bastante espaço em branco (ou "em preto"), fotos em alta qualidade, grid organizado.

3. BOTÃO FLUTUANTE DE WHATSAPP (fixo)
Ícone do WhatsApp fixo no canto inferior direito, em todas as telas.
Ao clicar, abre conversa já com mensagem pré-preenchida (ver seção 5).
Deve ter uma pequena animação de "pulso" para chamar atenção sem ser irritante.
4. RESPONSIVIDADE E PERFORMANCE
Mobile first, testado em telas pequenas.
Imagens otimizadas (lazy loading).
Animações leves de entrada por seção (scroll reveal).
SEO básico: title, meta description, og:image, favicon com o monograma RB.
Acessibilidade: contraste adequado, textos alternativos em imagens.
5. FLUXO DE AGENDAMENTO — ESSA É A PARTE MAIS IMPORTANTE

Eu não quero um botão simples de "abrir WhatsApp". Quero um fluxo guiado, onde o cliente primeiro confirma o horário disponível pela conversa no WhatsApp, e só depois cai no link/confirmação de agendamento. Siga exatamente esta lógica:

Passo 1 — Clique em "Agendar" Todos os botões de agendamento do site (header, hero, serviços, contato, botão flutuante) devem abrir o WhatsApp (via link https://wa.me/5511987267087) já com uma mensagem pré-preenchida perguntando pelo horário disponível, por exemplo:

Olá! Vim pelo site da Studio Black7 e gostaria de saber os horários
disponíveis para agendar um corte. Pode me ajudar?
Se o botão for de um serviço específico (ex: "Corte + Barba"), a mensagem deve incluir o nome do serviço automaticamente:
Olá! Vim pelo site e quero agendar: Corte + Barba (R$ 50,00).
Quais horários vocês têm disponíveis?

Passo 2 — Consulta de disponibilidade (conversa no WhatsApp)

O atendimento a partir daqui acontece dentro do WhatsApp (manual ou com um bot/atendente automatizado, se o cliente tiver isso configurado).
Estruture o site para que, visualmente, fique claro para o usuário que primeiro ele confirma o horário com a barbearia, depois o agendamento é fechado — ou seja, evite dar a entender que existe uma reserva automática/instantânea sem confirmação humana.
Sugestão de copy no site, próximo aos botões de agendamento:

"Clique para consultar o horário disponível no WhatsApp e confirmar seu agendamento."

Passo 3 — Link de agendamento final (opcional, complementar)

Depois de confirmado o horário no WhatsApp, o site pode direcionar/reforçar o link do "InBarber App" como ferramenta de agendamento online complementar, para quem já sabe o horário e quer só formalizar (deixe essa seção com o botão "Agendar pelo app" apontando para o link do InBarber).
Deixe claro na UI que existem 2 caminhos:
WhatsApp → consulta e confirmação de horário (fluxo principal, recomendado).
InBarber App → agendamento direto para quem já sabe o horário desejado.

Se for possível integrar via API (Lovable + backend/automação):

Estruture o botão de agendamento para futuramente se conectar a uma automação (ex: n8n, Make, Zapier ou WhatsApp Business API) que:
Recebe a mensagem do cliente.
Consulta uma agenda (Google Calendar, planilha ou banco de dados) com os horários livres do dia.
Responde automaticamente com as opções de horário disponíveis.
Ao cliente escolher, gera e envia o link/confirmação final de agendamento.
Deixe o código do site preparado (variáveis, componentes, webhook placeholder) para receber essa integração futuramente, mesmo que hoje o fluxo comece manual pelo WhatsApp.
